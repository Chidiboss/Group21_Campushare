# Campushare

A campus-only student marketplace to buy, sell or give away pre-owned items.

## Problem
Students end up with items they don't need (shoes that don't fit, old textbooks),
and there's no dedicated campus-only place to pass them on. Wrong size or fit is
the top reason for online returns based on the high percentage 44% in the Shorr survey.

## Features
- Registration and login with campus email
- Student profiles
- Item listings (for sale or free giveaway)
- Categories and search
- Buy / giveaway requests, with accept or reject
- Transaction tracking
- Notifications
- Admin dashboard

## Tech Stack
- Frontend: React (installable as a PWA)
- Backend: Java, Spring Boot REST API
- Database: MySQL
- Tools: IntelliJ IDEA, VS Code, Postman, Figma, Git & GitHub

## Methodology
Incremental model with short Scrum-style sprints (4 increments).
